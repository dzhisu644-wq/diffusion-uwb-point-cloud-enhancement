# Code provenance

The diffusion and consistency-model implementation in `diffusion_X7/` is
adapted from [Radar-Diffusion](https://github.com/ZJU-FAST-Lab/Radar-Diffusion),
released by ZJU FAST Lab under the MIT License. Radar-Diffusion in turn builds
on OpenAI's consistency-model implementation and k-diffusion. The original MIT
license is retained in `LICENSE`.

The preprocessing, experiment configuration, UWB/LiDAR dataset interface, and
evaluation utilities in this repository contain modifications for the NOVELDA
X7 and RPLIDAR A1 experiments described in the accompanying paper.
